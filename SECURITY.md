# Security Policy

## Project Nature

**Cyberpunk Smart City Under Attack** is an **educational cybersecurity simulation project**.

This project:
- Simulates fictional cyber incidents in a fictional smart city
- Contains no real hacking tools, exploit code, or network attack scripts
- Makes no external network connections
- Does not process real personal data
- Is intended for school exhibitions, classrooms, and cybersecurity awareness events

## Ethical Use Statement

This project **must not** be used to:
- Target real computer systems, networks, or devices
- Attempt unauthorized access to any system
- Conduct real penetration testing without explicit written permission
- Cause disruption to real infrastructure of any kind

The scenarios, events, and defensive actions in this project are **entirely fictional** and are designed to teach defensive cybersecurity concepts. All event log messages are prefixed with `[SIMULATION]` to make this clear.

## Safe-Use Commitment

All contributors to this project commit to:
- Keeping all simulation logic entirely local (no external API calls)
- Never including real vulnerability databases, exploit payloads, or scanning tools
- Ensuring all educational content promotes ethical, defensive thinking
- Clearly labeling all simulated content as simulation

## Reporting Security Issues in This Code

If you discover a genuine security vulnerability in this project's code (not in the fictional simulation content), please report it responsibly:

1. **Do not** open a public GitHub issue for security vulnerabilities
2. **Email the maintainers** at the address listed in the repository's About section, or
3. **Use GitHub's private security advisory feature** in the repository Settings > Security tab

Please include:
- A description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if you have one)

We will acknowledge your report within 48 hours and work to address it promptly.

## Hardware Safety

If you build physical hardware extensions (LED displays, ESP32 controllers) for this project:
- Never connect hardware to real city infrastructure or control systems
- Only use safe, low-voltage electronics suitable for exhibition models
- Follow all applicable electrical safety standards
- Ensure your exhibition environment has appropriate supervision

## Disclaimer

This is a student/educational project. The creators are not responsible for any misuse of the concepts taught in this simulation outside of ethical, authorized, and legal contexts.
